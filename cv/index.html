产品档案

企划星的产品定位、矩阵、里程碑与技术栈。内容维护在 `_data/cv.yml`。

基本信息

名称 企划星 planstar
定位 企划支持平台（投票决策类应用）
核心机制 立项前星推官投票（不扣星币）→ 立项后回报档位支持
企划分类 游戏创作、自媒体、小说创作、周边同人等
维护者 @uifj

产品矩阵

  • 1.0.1
    企划星 Flutter 客户端
    移动客户端
    • monorepo + Clean DDD + Riverpod + GoRouter，15 个功能域垂直切片。
    • 四个主 Tab：首页 / 发现 / 企划（星推官审批）/ 我的；星币商城、榜单、搜索、订单闭环。
  • 重写版
    企划星桌面日历清单
    Windows 桌面端
    • 完全复用移动端 core 与 core_design_system，不引入第二套视觉与状态方案。
    • 原生通知、多窗口、托盘、开机自启、农历；用户级安装器覆盖升级。
  • Kratos v3
    Planstar 后端 API
    业务服务端
    • 单一二进制，10 个 planstar_* MySQL 域库；Redis / RabbitMQ / Elasticsearch。
    • Consul 注册、Jaeger 追踪、Prometheus 指标；本地三容器一键联调。
  • 独立模块
    Admin 运营后台
    运营服务端 + 控制台
    • Kratos + AIP + ent + Wire + buf 生成链路；只读业务库、只写运营库。
    • 审核与举报代理到 planstar 运维 API；Vue/Vite 控制台经 nginx 部署。
  • Next.js 15
    Planstar Web 官网
    官方网站
    • pnpm workspaces + Turborepo；design-tokens / ui / api-client / config 四包。
    • 后端不可用时楼层独立降级，页面不崩溃。

    • Go 1.26 · Kratos v3（裸 net/http）· MySQL 8.x ×10 · Redis · RabbitMQ · Elasticsearch
    • OTel / Prometheus / Jaeger / Grafana / Consul
  • Web
    • Next.js 15 App Router · React 19 · TypeScript strict · Tailwind CSS v4
    • pnpm 9 + Turborepo 2 · Vitest + Playwright
